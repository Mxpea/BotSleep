# 狩猎、战斗与桶类操作

本轮针对 Java 1.21.11 / 官方 mc-agent-api 1.3.14 实现；2026-11-16 查阅资料。适用于普通生存模式的已观察实体，不面向玩家对战。只有离线证据的功能不能记成实服击杀或完整生存验收。

## 主流程入口

- `hunt_animal(entity_id, expected_name)`：猪、牛、羊、鸡的近距狩猎。
- `fight_hostile(entity_id, expected_name)`：骷髅、僵尸、苦力怕的一次短战斗步骤。盾、近战武器、弓弩和弹药由当前库存决定。
- `collect_liquid(pos, expected_name)`：取当前明确 `level=0` 的水源或岩浆源。
- `hunt_with_lava(entity_id, expected_name)`：仅在已有不燃容纳坑内，对猪、牛、羊、鸡短暂放岩浆并回收。

工具通过 daily/competition 的工具目录、参数验证和 harness 分派进入生产链。近敌时，符合条件的本地短步战斗不等待大模型；不符合条件则撤退/等待。模型提案执行前仍重新观察；所有模型调用继续经过唯一请求槽。

## Starter 自保

`starter` 在本地调度 `fight_hostile`，模型工具仍为 9 项。只有单只僵尸进入 1.5–2.8 格，当前剑或斧、饥饿、生命、干燥落脚和射线均通过复核时才反击一击。木质和金质武器要求满血。其他武器沿用有盾至少 14、无盾至少 18 生命的门槛，饥饿至少 8。

已有撤离或撤退搜索仍在冷却时，继续执行撤退策略。挥击前用最终状态复核威胁。发现第二只敌怪、远程威胁或站位变化时，取消反击并交由 harness 重新判断撤退方向。可选装备采样失败时保留原有近敌快照，撤退技能执行前核验当前状态与地形。

攻击后重新观察，伤害未确认时保留相应证据。发出写入前的读取失败与 API 明确拒绝换装可重新规划。写入结果未知时保留 `pending` 并暂停。

## 普通狩猎

1. 复查目标 ID、物种、位置、生命、饥饿、落脚和射线；需要剑或斧。玩家、宠物、其他动物或掉落物可能被误击/横扫时拒绝。
2. 目标须在 2.8 格内。远目标由主流程先选择安全接近动作；狩猎技能自身不调用 `/attack`，不自动追到危险地形，也不追掉落物。
3. 按武器冷却进行最多 4 次单挥击；狩猎 helper 有 8 秒预算，内部读取最多 1.5 秒且不超过剩余时间，外层通用 readiness 读取另受客户端超时限制。每次重新核对目标与自身状态，最后一轮扫描的坐标用于实际瞄准；动物跑远、受伤、目标变化就停止。
4. 成功只认预期生肉、熟肉、皮革、羊毛或羽毛的实际库存增量。目标消失不证明击杀；仅有 `hits` 也不证明造成伤害。未收集掉落通过现有 `collect_drops` 后续处理。

用着火动物取得熟肉只是一种可能结果；没有火焰状态证据就不宣称已经点燃。API 未提供动物年龄、归属或繁殖冷却，不能声称已识别成年、野生或可繁殖个体。

## 有盾与无盾战斗

| 情况 | 实现行为 |
| --- | --- |
| 有盾、单只骷髅/僵尸进入近战范围 | 至少 14 生命、8 饥饿；朝向目标、举盾并留启用时间，短暂降盾单击，再复查并恢复防御。 |
| 无盾、单只骷髅/僵尸进入近战范围 | 至少 18 生命、8 饥饿；具备武器与已确认落脚时单击；不以连续掉血硬换伤害。 |
| 有弓/弩和普通箭 | 对 6–12 格内的骷髅/僵尸、8–12 格内的苦力怕单发；检查射线、旁观实体、弹药或抛射物证据。 |
| 苦力怕靠近 | 检查退出走廊后短退，不能走则返回明确撤退需求；有盾可面向防御，但不把盾当作爆炸安全保证。 |
| 多敌、玩家/旁观实体干扰、低血、危险脚下、变化的目标 | 拒绝进攻，交回撤退/等待与重新规划。 |

每次最多一击/一发；结果分开记录 `attack_sent`、`damage_verified`、`killed`、`completed`。敌人健康字段缺失时不能把挥击或射箭当作命中；实体消失也不自动当作击杀。赛事怪物猎人只认服务端 advancement。

交战有按生命周期、实体 ID/名称隔离的步数、时间与无进展预算：同次遭遇最多 6 次近战/4 发远射或 20 秒；连续 3 次近战/2 次远射没有确认伤害就要求撤退，并冷却 30 秒。规则规划和模型规划共享撤退门禁；已知失败要求撤退时及时重新观察，不因先前生产失败的累计阈值跳过这次撤退。盾姿态由技能拥有，威胁结束后才在新鲜安全状态下解除；未知写结果不会通过解除姿态来试探。

**苦力怕的近战击杀仍未开放**：当前实体 API 没有引信、膨胀或 charged 字段，不能编造“还有几秒可以再砍一刀”。有无盾都可在合适距离使用已实现的弓弩路径；不具备条件则撤退。弓弩充能请求有短暂不可轮询区间，因此不用于贴身补救。

## 岩浆桶的条件与恢复

普通取液要求近距站位、不在自身列、源方块明确、视线可达、已有空桶和足够容量。不会让 API 自动走到岩浆边；水源可能自动再生，不能要求无限水源一定变空气，但桶增减必须匹配。岩浆取源还须确认源格移除。

岩浆狩猎只允许：

- 主世界白天、无雷暴，生命至少 16、饥饿至少 10，已有岩浆桶和空余格。
- 动物位于现成单格坑中；底部与两格高侧壁是不燃、不下落的完整方块。机器人站在坑沿上方，源格在无需移动的交互距离内。
- 放置与取液分别核对官方实际瞄准射线：满桶向下方支撑顶面瞄准，空桶向液面瞄准。只看取液射线可能漏掉遮挡放置的坑壁，这种站位禁止倒岩浆。
- 对周边 7×7、源下 1 格至上 4 格的范围做有限白名单检查；草、树叶、木建筑、液体和未知方块均不通过。附近有其他实体或掉落物也不通过。
- 放置后核对实际 `target`、岩浆源、满桶减少和空桶增加，然后立即收回；核对源格为空与桶数量恢复，不停留等待动物烧死。

没有食物增加时返回 `hunt_unverified`，明确 `source_recovered` 和下一步观察/拾取建议；同实体 30 秒内不再次点燃。既不把放岩浆当击杀，也不保证掉落不会被烧毁。

请求或后验不确定时返回 `action_unconfirmed`，保留 pending、源坐标和 `lava_outstanding/recovery_required`，禁止重复点燃、盲目收桶或追加清理动作。已明确确认放置、随后收到取消时，只允许核验并收回这个确切源；恢复失败则继续保留未知。普通取液若在写后取消、死亡、换生命或断线，同样不能清掉 pending。

## 研究依据与版本限制

- [Minecraft：Shield](https://www.minecraft.net/nl-nl/article/taking-inventory--shield)：前方防护、使用时减速及斧破盾；程序不能把持有盾等同于当前所有伤害都可格挡。
- [Java 1.21.5 更新说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-5)：防御物品组件与启用/角度等规则；第三方服务自报 blocking 不是服务端命中证据。
- [Minecraft：Lava](https://www.minecraft.net/sv-se/article/block-week-lava)：接触伤害、持续燃烧、点燃周围可燃物。文章较旧，其中地下生成高度不用于本版本导航；只取与当前 API/规则一致的基本危险机制。
- [Minecraft：Bucket](https://www.minecraft.net/ja-jp/article/taking-inventory-bucket)：桶的取液与容器用途；本模块不将倒水、取液、炼药锅和空放物品混为同一操作。
- [Minecraft：Recovery Compass](https://www.minecraft.net/ja-jp/article/taking-inventory--recovery-compass)：岩浆可销毁普通掉落物，所以“烧死”与“拿到食物”必须分别验证。
- [Minecraft：Mobs](https://www.minecraft.net/en-us/article/minecraft-mobs)、[Shears](https://www.minecraft.net/fi-fi/article/taking-inventory--shears)：动物资源、剪毛替代方案与敌对实体差异。剪毛/繁殖本轮尚未绑定为工具。
- [官方 API 1.3.14 源码](https://github.com/Zyzzyva0381/mc-agent-api/blob/37be500/src/session.js)：`attack` 会跟随并在目标消失后尝试拾取；`control` 返回射线挥击而非服务端伤害；`posture` 是完整设置；桶通过视线使用；`shoot` 返回发射和抛射物信息。

完整日常与速通阶段、1.16.1 与 1.21.11 差异及尚未绑定的下界/末地动作见 [SURVIVAL_PLAYBOOK.md](SURVIVAL_PLAYBOOK.md)。联网资料提供策略依据，最终动作仍受当前游戏证据和本地技能门禁约束。
