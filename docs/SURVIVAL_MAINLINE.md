# 无龙普通生存服的通关主线

当前世界的终点是一个能长期维持食物、工具与住所的基地。普通的 `daily` 生存配置默认按章推进。已有自定义 `operator_goal` 或 `local_opening` 的配置可用 `survival.autonomy.mainline: true` 显式切换。程序每次完整观察后选择第一个欠缺的章节，本地长任务处理前置和失败。实时监控的「生存主线」显示当前章节。饥饿、伤害、危险生物和夜间避险可以中断施工，安全恢复后程序继续检查章节条件。

在 `survival` 下设置 `continuous: true` 可让日常生存一直运行。死亡次数只作统计，重生后重新读背包和周围环境；总步数、总时长和连续行动失败都不会结束本轮。单个长任务仍有步数与时间限制，用尽后重新选择行动。若一次写入的结果未知，程序先做只读复查，再根据当前状态决策。短暂断线或上游死亡冷却会进入退避，继续使用原会话重连。手动暂停、停止进程仍然有效。需要有界测试时可使用 `--once` 或 `--max-steps N`。

| 章 | 目标 | 本地执行与完成依据 |
|---|---|---|
| 1 | 工作台与木镐 | 空手找树、采木、做板与木棍、放置可用工作台。背包已有木镐或更高等级的镐即可通过。 |
| 2 | 第一把石镐 | 优先采可达露石。没有合适露石时，从自然地表调查阶梯；逐格挖出上下行空间、取得至少 3 块圆石，沿原路上返，在可用工作台用 3 圆石、2 木棍制镐。以背包中的石镐或更高等级镐为准。 |
| 3 | 应急口粮 | 寻找已有可吃掉落、农作物或适合狩猎的动物。首次目标为 4 份可食物品；配置的储备更低时使用配置值。低血量或临界饥饿可提前触发求生。 |
| 4 | 闭门住所 | 寻址、备齐材料，分步搭墙、封顶并安装门。有已开工的工程就回原址；现场核对地板、墙、屋顶、可用出口和关闭的门。 |
| 5 | 石器工具组 | 石镐、石斧、石剑逐项核对。缺材料沿用本地采石流程；高级同类工具可满足前置。 |
| 6 | 熔炉投入使用 | 缺炉时采 8 块圆石并制炉；持有炉时通过熔炼任务放置，再观察真实炉块与输出。 |
| 7 | 燃料 | 核对煤与木炭总数，默认达到 8；不足时以原木烧木炭，检查炉内任务与实际收取数量。 |
| 8 | 火把 | 以煤或木炭配木棍制作，背包至少 4 支。这一章记录照明物资，建筑的实际亮度另行观测。 |
| 9 | 床与过夜 | 取得同色羊毛与木板，制作并在住所合适位置安床，现场核对两半床体；夜间由睡眠逻辑检查能否实际入睡。 |
| 10 | 储物 | 备料制作箱子，放置并检查其可访问性。后续观察用同世界的地点提示回访设施。 |
| 11 | 铁器与防御 | 用石镐寻找并采集铁矿，熔炼、生铁锭入包，然后制作铁镐、斧、剑、盾与桶。附近暂时没有可采铁矿时，记录缺少的前置并在本章恢复。基础阶梯的任务是供圆石，深层寻铁另有独立工作流。 |
| 12 | 可再生食物 | 准备锄与种子，识别有水源的土地，耕种并复核种植。现场种植证据用于长期生产判断。 |
| 13 | 日常食物库存 | 补足配置的 `daily.food_reserve`，默认 8 份。库存看真实背包，已吃掉的食物会触发补充。 |
| 14 | 维护木材 | 补足 `daily.wood_reserve`，默认 8 个原木当量；4 块木板折算 1 个。程序只请求缺口对应的 `gather(resource=logs)`。 |
| 15 | 持续维护 | 重检当前食物、燃料、工具和基地任务。消耗、死亡或设施确实受损后，重新执行第一个欠缺章节。持续维护没有一次性“胜利”指令。 |

### 采石、复查与模型的分工

- 阶梯入口与方向从当时地形确定。每一步先读脚下支撑、目标、头部空间、附近危险和退路，再执行一次挖掘或一次移动。反复探查已知坏入口会命中本地冷却。入包数量达到目标后，先回到入口，再制作石镐。
- 树冠清叶的回复不确定时，检查点保留原请求。机器人至少两次读取叶格、人物生命、脚位和支撑。叶子还在就排除该目标并重新规划。跌落后先核实新落点；若旧动作之后已有明确死亡记录，则核实重生点和背包，作废旧路线，按现有装备恢复主线。两种情况下都保留原挖掘结果未知。自动模式每个已证实的新生命世代最多触发一次额外复查，手动暂停继续有效。
- 日常主线在正常推进时直接启动本地程序。只有本章恢复用尽时才进入串行模型修复，恢复目录约束了可以请求的长任务。模型仍返回旧任务名 `wood_reserve` 时，解析器将其规范为 `gather` 与 `resource=logs`，再走本轮真实工具参数校验。
- 入夜时，若机器人在已核实的住所附近，会检查通向实际外门的同层步行路线。整条路线在 16 格范围内、支撑和净空都合格且路段无威胁时，每次只走一格。每步重新观察，最后开门、进屋、关门。路线被封或遭遇敌人时，由原有避险逻辑接手。

### 含末影龙的普通 Java 世界

通用冒险路线可在基地准备之后延伸为「随身口粮与防御 → 下界门与回程通道 → 要塞与烈焰棒 → 末影珍珠、烈焰粉与末影之眼 → 定位主世界要塞 → 检查并补全末地门 → 入末地、清理水晶、击败龙并返程」。当前服务器采用前述无龙终点。独立门户与洞穴模块的绑定情况以及下界、要塞和末地阶段所需证据见[生存与速通阶段建议](SURVIVAL_PLAYBOOK.md)。游戏机制参考 Minecraft 官方的[第一天生存](https://www.minecraft.net/zh-hans/article/how-survive-your-first-day)、[要塞](https://www.minecraft.net/en-us/article/stronghold)和[末影龙](https://www.minecraft.net/en-us/article/ender-dragon)。
